# 勾选是目录，限额按功能

取代 `0028` 里「全局最多同时启用 2 家」。文件长度、媒体时长、历史和继续对话仍按 `0028`。

翻译服务和识别的勾选只表示已经配好，放进目录。免费也能勾多家。谁真正出字，由每个功能自己的默认决定。

识别相关的功能免费只用默认那一家，当次也不能再加：截图识别、语音输入、实时字幕、媒体字幕、朗读。Pro 在正在用的界面里从目录再加，这次结束就丢，不写回设置。

翻译按功能。划词、剪贴板、截图各一份列表，免费同时最多两家。文件、语音输入、实时、媒体免费只跑默认一家。快捷翻译仍是一家，不改。Pro 可以多家；浮层、实时和媒体里临时加的不写回。

## 考虑过

- 免费仍限制目录里最多勾两家：配好第三家就要先关掉一家，和「勾选只是启用」不是一回事。
- 识别的多路也写进设置：免费和 Pro 会在设置里看到两套东西，当次加的路下次还在。
