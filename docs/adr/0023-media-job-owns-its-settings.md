# 每份片子自己的配置，同时份数可以改

跑完写在片子旁边这一点，被 `0044-captions-export-by-hand.md` 取代。

一份媒体字幕记自己的识别引擎、识别语言、译成和翻译服务。拖进来时抄上一次记下的值。还没开始，或已经落盘，选中这一行就能改；改动记下来，下一份照抄。正在识别或正在等翻译的那一份保持开跑时的配置。

同时份数只数正在识别和正在等翻译的。默认 5，在偏好设置 › 通用里改，从 1 到 10。列表可以更长。多出来的停着，要点开始才跑。已经满了再点开始，就告诉你，不在背后接着跑。

点停止仍先等已经发出的翻译落盘。落盘之后可以再点开始，从起点重新识别，屏上的段清掉，写完再盖掉旁边的 SRT。自然跑完的也可以再点开始。正在等翻译时不能再转。不从停下的时刻接着识别。

点开始之后，下面可以播放这份音视频，字幕列表还在。纯音频就播声音，先停着，等人按播放。识别按自己的速度跑，不跟着播放。还没点开始时不放播放器。

## 考虑过

- 整窗一套，开始时再抄到这一份上：两份片子不能各用各的语言。
- 第 6 份直接不收：上限是同时在跑的份数，不是列表有多长。
- 满了就自动接着跑：关掉窗口才发现后面还在跑。
- 从停下的时刻接着识别：一次识别被切成两截，旁边那份 SRT 对不上从头到尾的一遍。
- 要再跑就清掉再拖：同一路径还在列表里，清掉才能再放下。
- 播放跟着识别走：识别比播放快，片子还没看完，字幕已经齐了。
- 还没开始就放播放器：起点和音轨还没定。
