# 导出按路，原文和译文可以合并或分开

这条被 `0043-export-follows-recognition-lane.md` 取代。导出改按识别路切。

实时字幕和媒体字幕都按翻译服务导出。一次导出只用一个选择：合并，或分开。

合并是这一路一份 SRT，一条里上面原文、下面译文。分别导出是这一路两份，时间轴相同，一份只有原文，一份只有译文。标记写在原文行前，按改过、删过之后的结果来写。译文行不写标记。

实时点导出时选。一开始是分别导出，之后记住上次的选择。媒体跑完写到片子旁边时用上次的选择，一开始也是分别导出。另存为时可以改。

文件名带上这家的名字。合并是 `名字.服务.srt`。分别导出是 `名字.服务.原文.srt` 和 `名字.服务.译文.srt`。这一路没译成的段仍进原文那份，不进译文那份。标记还在的段，原文行前写上当前这枚标记。

实时一次选一个文件夹，全部写进去。媒体写在片子旁边。

## 考虑过

- 只导出当前看着的那一路：其余几路的译文没有文件。
- 几路译文写进同一份：播放器里分不开是哪家译的。
- 分开仍是一份文件、两条字幕轨：常见播放器只认一份里的一行字幕。
- 媒体每次跑完都问合并还是分开：几份同时落盘会连着问。
