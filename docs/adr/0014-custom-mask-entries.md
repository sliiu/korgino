# 自定义按条添加，普通和正则分开

自定义遮盖一条一条加。每条自己选普通或正则，也可以单独不区分大小写。普通按字面找，英文词两边要断开，短于两个字的不算。正则匹配表达式写到的那一段，边界由表达式自己决定。

写错、太长，或会匹配空字符串的正则，这一条不生效，也不拦住别的发送。命中之后仍先确认。

以前用逗号写在一栏里的词，会变成一条条普通条目，并带上当时的大小写开关。

## 考虑过

- 整栏共用一个「这是正则」开关：词和表达式混在同一格里，没法一条是词、另一条是正则。
- 写错的正则让整句发不出去：设置里打错一个括号，翻译就全停。
- 正则也强制按词断开：那就写不出有意匹配词中间的表达式。
