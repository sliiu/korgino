# 菜单栏画出连按空格，列表在时间旁标取得方式

媒体字幕和其他菜单功能一样有一条快捷键，默认是 ⌥⇧M。勾选同时管菜单项和这条快捷键。

快捷翻译的默认是连按三下空格。系统菜单的按键栏只能放一个按键，空格本身在那里几乎看不见。这一行自己画标题，按键栏放三个空格符号。偏好设置里仍写「空格 ×3」，那是给人读的名字。改成组合键之后，回到系统的按键栏。

历史和收藏每一行，时间左边放取得方式的图标。左边那一列仍是来源应用的图标；没有应用时仍用取得方式的图标占位，行才对齐。划词和快捷翻译常常来自同一个应用，时间旁边的图标用来把它们分开。

## 考虑过

- 按键栏写「空格 ×3」。那是说明，不是快捷键符号，和其他行的 ⌥⇧ 对不上。
- 把三个空格符号写进菜单标题。标题和按键栏对不齐，高亮时字色也不会跟着变。
- 用菜单徽章。徽章是数量，不是快捷键。
- 媒体字幕默认用 ⌥M。实时字幕、文件、词典、历史都是 ⌥⇧ 加一个字母，媒体字幕跟着这一条。M 还没有被占用。
- 时间旁边的图标换掉左边那一列。没有来源应用的行会少一块，列表左边参差不齐。
