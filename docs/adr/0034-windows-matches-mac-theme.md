# Windows 用和 Mac 同一套画风

取代 `0031` 里「不移植自定义绘制」那句。两边的窗口用同一套数值：面板圆角 16，卡片圆角 10，浅色窗口底 `#F4F4F6`、卡片白，深色窗口底 `#1C1C20`、卡片 `#2A2A2F`，发丝边是前景色 8% 不透明度。分区标题 11 磅半粗、次要色。正文 13 磅。搜索框、悬停底板、分段药丸、勾选行、芯片和细滚动条都按 Mac 上这几件的尺寸和颜色画。托盘用现在的单色模板图标。供应商图标用现成的那套图。SwiftUI 里的 SF Symbol 在 Windows 上换成同一套单色图标，不用彩色的系统图标。

控件仍是 WinUI，SwiftUI 视图不共享。只有 macOS 才有的毛玻璃，用上面的纯色代替。

## 考虑过

- 保持 WinUI 默认外观。功能对齐，画风分成两套。
- 把 SwiftUI 视图原样搬过去。WinUI 画不出那些视图。
