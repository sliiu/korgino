# 上架之后只留商店包

公证包只发到 Mac App Store 上架之前。上架之后停发，只留商店包。Pro 在用户已经打开的商店包里买，不必再装一份。

上架前没有商店收据，购买和 14 天试用都还不能开始。功能开关和上架后的商店包是同一套。

## 考虑过

- 上架后继续发公证包给不付钱的人：要 Pro 的人会装着两份，付完款离开先装的那一份。Developer ID 的包完成不了这笔 App Store 付款。
- 公证包里另做网页付款和本机许可：和 StoreKit 各记各的，国内用户还要另接微信或支付宝。
