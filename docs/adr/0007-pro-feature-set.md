# Pro 是这四项，实时字幕本身免费

偏好设置里的 Pro 是一次购买，另有 14 天试用。付费档是云端语音识别、文件翻译、不限数量的翻译服务和 AI 提供商、完整历史。实时字幕免费就能开，免费时识别只用 Apple 本地。

这条取代 `0004-live-captions-one-time-unlock.md`。0004 把实时字幕整段放进付费档，和现在的套餐不一致。

## 免费时的边界

- 划词、截图、剪贴板、词典、释义、对话、收藏不收费。
- 实时字幕可以开。识别固定 Apple 本地，不能添加或启用云端识别。
- 同时启用的翻译服务最多 2 个。其中要密钥的传统引擎最多 1 个，AI 最多 1 个。
- 历史显示最近 50 条。记录最多留 200 条，Pro 能看见留下来的全部。

## 考虑过

- 只把实时字幕放进付费档：免费用户会打不开文件翻译，也和偏好设置里列出的四条对不上。
