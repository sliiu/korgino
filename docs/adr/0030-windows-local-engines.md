# Windows 用系统 OCR 和小型 Whisper，不带离线翻译

模型档、界面名字和下载时机见 `0032`、`0033`。

Windows 没有 Apple 的本地翻译、本地语音和 Vision。截图识别用 Windows 自带 OCR。实时字幕和媒体字幕的本地识别用一份小型 Whisper，免费档仍然不能改选云端识别。不放进安装包。不打包离线翻译，翻译服务列表里不出现 Apple 本地。Windows 新装只默认启用 Google（免费）。国内没代理时，第一句划词会失败。

## 考虑过

- 用 Windows 自带语音顶 Apple 语音。它接不上系统声音的环回，也盖不住要听的外语。
- 再打包一套离线翻译，保住 Mac 上「没网也能出第一句」的默认。语言对和模型体积会变成另一件产品。
