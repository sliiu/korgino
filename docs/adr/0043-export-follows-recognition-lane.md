# 导出按识别路切

这条被 `0048-export-sheet-rule-and-source.md` 取代。导出改成选规则，原文按路勾选。

取代 `0038`。实时和媒体仍共用一次选择：合并，或分开。一开始是分开，之后记住。分开时可以不要原文，这个也记住。

合并是一路一份。一条里上面是这条路的原文，下面是它绑上的译文。文件名带采集和识别，例如 `名字.系统声音.Apple.srt`。媒体没有采集，就不写采集。

分开是一路乘一家翻译一份，时间轴相同。一份原文，一份这家的译文。可以不要原文。路上没绑翻译时，只要原文。没译成的段不进译文那份。标记写在原文行前。

## 考虑过

- 仍按翻译服务切：同一家翻译绑在两条识别上时，两份原文会写进一个文件。
- 合并时几家译文各一份：一路的原文会被复制好几遍。
