# 导出时选规则和带不带原文

取代 `0043`。实时和媒体点导出时弹同一张表，选择记住。

规则二选一：

- 按识别路：一路一份。一条里上面是原文，下面按绑定顺序放每条绑定的译文。文件名带采集和识别，例如 `名字.系统声音.Apple.srt`。
- 按各自翻译：一条绑定一份。文件名再带翻译和语言，例如 `名字.系统声音.Apple.Google.英语.srt`。

原文按路勾选，一开始全勾。可以全不勾，也可以只勾某一路。按识别路时，不勾的那路文件里只有译文。按各自翻译时，勾上的路每份是原文在上、译文在下，不勾的只有译文。「不翻译」那条绑定导出的就是原文，不看这个勾。

不勾原文、这一路又只有「不翻译」时，这一路照样出原文那份。某条绑定没译成的段不进这条绑定的那份；按识别路时这一条只少这一行。标记写在原文行前；不带原文时写在第一行译文前。

媒体没有采集，文件名里不写采集。实时一次选一个文件夹，全部写进去。媒体照 `0044` 手动导出，用同一张表。

## 考虑过

- 仍是合并或分开二选一：原文只能整体要或不要，挑不出某一路。
- 按各自翻译时原文单独一份：「不翻译」那条绑定已经是这一份。
- 每次导出都从全勾开始：常用的那套每次重勾。
