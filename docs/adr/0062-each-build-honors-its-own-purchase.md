# 两份都卖，各认各的购买

商店包和公证包都继续卖。商店包只认商店购买，含 14 天试用。公证包只认直接购买，没有试用。在一份里付过的钱，另一份不当作已购买。换包安装的人要在新的那一份里再买。

直接购买的收款是自己的支付系统，付款时必填邮箱。系统交回一把钥匙，公证包认这把钥匙。忘了就在公证包里填那只邮箱，发回的是同一把。一把钥匙最多同时用在 3 台 Mac 上。同一台重装不新占名额。第 4 台填入时自动停掉第一台填入钥匙的那台，不是最久没打开的那台。被停掉的那台若当时没网，要到下次连上系统才变回免费档。同一台再填这把钥匙，仍算当初那一台，第一次填入的时间不变。已经让出名额的那台再填，是一次新的填入。

有网时再对一次钥匙。退款或名额被让出，在下次连上时失效。连不上就保持上次的结果。连不上和「这台已经不在名额里」是两回事。

占着名额的这台可以在关于页自己让出，只让出自己，不停别的电脑。有网当时就让出。没网先记在本机，让出完成前仍算已购买，名额要等这台连上系统才空出来。这段时间里第 4 台填入，停掉的仍是第一台。启动时和翻译中不弹窗。

这把钥匙只解开 Mac 公证包。Windows 不认，仍按 `0029` 用开发开关。

同一邮箱再付一笔，得到另一把钥匙，各自 3 个名额。补发时这只邮箱上的每一把都发。退掉其中一把，只影响那一把的名额。

商店包和公证包用同一个标识 `com.sliiu.KorgiTranslate`。后装的那份变成打开的那一份。商店包的更新只走 App Store。检查 GitHub 只在公证包。应用留购买、填写钥匙和按邮箱补发的接口，不接具体支付渠道。

这条取代 `0012-store-build-only-after-launch.md`。`0008` 只还描述商店包。

## 考虑过

- 上架后停发公证包：两份都留着卖。
- 商店包也认网站上的付款，公证包也认商店收据：公证包验不了商店收据。接受换包就再买一次。
- 两个标识、两份同时装着：设置和全局快捷键会有两套。
- 钥匙不限台数：钥匙传出去就一直能用。只限一台：重装后机器对不上就填不回去。
- 第 4 台由人点选停掉哪一台：人常常不在旧电脑旁边。改成自动停掉。
- 停掉最久没有来对过钥匙的那台：每天在用的第一台不会被挤掉。改成停掉第一台填入的，哪怕它仍是每天在用的那台。
- 退款后已填过的电脑一直是 Pro：退款收不回。每次启动都向系统对钥匙：系统停一阵，付过钱的人变回免费档。
- 钥匙也解开 Windows：名额刚定成 3 台 Mac。Windows 要卖再单定。
- 同一台重填就算最新：重装可以把「被停掉」转给别的电脑。
- 再付一笔仍是原来那把钥匙：多付的钱不增加名额，也会换掉已经发出去的那把。
- 商店包也检查 GitHub：同一标识下会装成公证包，商店购买不跟着走。
- 占着名额的电脑不能自己让出：卖掉的电脑一直占着名额，新电脑填入时停掉的仍是第一台填入的那台。
