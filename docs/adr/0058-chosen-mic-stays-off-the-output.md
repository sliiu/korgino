# 选中的麦克风不接进输出

实时字幕选了一只麦克风再开始，会报 `com.apple.coreaudio.avfaudio` 错误 -10875（音频单元初始化失败）。系统默认那条不受影响。

输入节点一创建，就已经按系统默认设备初始化过。不先卸掉这次初始化，`CurrentDevice` 改了也不换设备。名单里的麦克风又常常只有输入，没有输出，比如 AirPods 的麦克风、内置麦克风、iPhone。它们的采样率也可以和当前扬声器不一样：这台机器上 AirPods 麦克风是 24 kHz，输出是另一台 48 kHz 的设备。把这只输入接到主混音器上，启动时要和输出一起初始化，就会失败。

选了具体设备时，先卸掉初始化，再改设备，只在输入上取音，不接到输出。没选设备时仍走原来的连接。不改系统的采样率，也不把采集改成另一套会话。
