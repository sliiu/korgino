# 成段每路都译，沉浸只是浮层

已经切好的段，译的是这条路当次绑上的翻译服务。没开沉浸字幕的也译。一路没绑翻译时只出原文。还没切成段的半句，只译这块沉浸字幕对应的那一家翻译。一块沉浸字幕是一路加上一家翻译。

每块沉浸字幕自己管原文、译文和朗读。底边留在这块放下的位置，多出来的高度往上长。

媒体字幕一段的原文下面，按路各放一行译文。开始前不再选翻译服务。落盘按路导出，原文和译文合并或分开见 `0038`。某一路没译成的段不进这一路的文件。

## 考虑过

- 没开沉浸就不译：窗口里看不成多家译文，开浮层才开始补译，会漏掉前面的段。
- 半句也给每一路译：没开浮层的路用不上草稿，接口会跟着识别结果连着打。
- 几块沉浸字幕共用原文、译文和底边：关掉一家的原文，另一家跟着没。
- 媒体仍写成旁边那一份 `原名.srt`：几路译文挤在一条字幕里，分不开。
