# 拖进来的音视频是媒体字幕

音视频按文件里的时间切段、翻译，存成一份 SRT。每条上面原文、下面译文；这一份里说话人多于一个时，原文行前加 `[n]`。它用文件自己的时间轴，所以不是第三路通道。文件翻译的原文是已经可读的字。音视频在识别出字之前还不是一份文本，所以不走那里。

媒体字幕单独一扇窗口，菜单里跟实时字幕并列。实时字幕窗口只听系统声音和麦克风。每一份自己记识别语言、译成、翻译服务和识别引擎。新拖进来的抄上一次记下的值。识别引擎起点是 Apple 本地。识别语言第一次是英语，之后记住上次。译成第一次跟应用的目标语言。翻译服务第一次用当前启用列表里的第一个，之后记住；没有翻译服务就不能开始。每份配置、同时份数、停下后再转和预览，以 0023 为准。

切段和实时字幕同一套：说到一句的收束、并且够长，才成为一段。时间是这句话在文件里的起止。按识别速度跑完，不跟着播放。SRT 放在片子旁边，文件名是原名加 `.srt`。旁边已有同名文件就盖掉。只收已经译好的段。没识别出来的空档不写空条。翻译失败的段不进文件。一段都没译好就不写文件。

同时在识别或等翻译的份数有上限，默认 5，在偏好设置里改。列表可以更长。多出来的停着，要点开始才跑；已经满了再点开始，就告诉你，不自动接着跑。不把正在跑的换成新文件。同一路径同时只占一行。一行上是文件名、识别到的文件时间、总时长、译好的段数。点一行看这一份的段。

识别可以从起点开始，一直到文件结尾。起点是文件里的一个时刻，字幕时间不从零重计。没有终点，也不另做「从上次停下的地方接着跑」。

拖进来不马上跑。一行先占着，起点默认 0，多音轨先选一条。点这一份的开始才跑，用的是这一份上的识别语言、译成、翻译服务和识别引擎。还没开始或已经落盘时可以改这一份；正在跑的不能改。跑起来不能改起点。点开始之后可以播放这份音视频，字幕列表还在。识别不跟着播放。还没开始时不放播放器。

在等开始、在跑、在等翻译、已经落盘，都占一行。落盘不自动清掉。清掉一行，已经写成的 SRT 还在。同一路径已经有一行时不再新开，指到那一行。停下或跑完并落盘之后，可以再点开始，从起点重新识别，写完再盖掉旁边的 SRT。正在等翻译时不能再转。打不开的不占行。原文已经是目标语言时，译文就是原文，不润色。

退出时，每一份在跑的都按停止处理：等翻译回来再落盘，然后退出。

和实时字幕可以同时开。同时份数只数媒体字幕。音视频拖到实时字幕或文件翻译上，打开媒体字幕并装上这个文件。文本和已有字幕拖到媒体字幕上，打开文件翻译。媒体字幕只收有声轨的音视频。旁边写不了时弹出保存面板，并说明没写成。

点停止只停这一份，先说明正在等翻译，等已经发出的翻译回来再落盘。其余继续。自己跑完也是等翻译回来再写。

识别和付费跟实时字幕同一条：免费用 Apple 本地，云端要 Pro。多条音轨时用第一条有声的；多于一条时，开始前选一条。遮盖走静默遮盖，不逐段确认。

## 考虑过

- 第三路通道：系统声音和麦克风没有文件上的零点，SRT 对不上片子。
- 放进文件翻译：识别出时间之前，它还不是一份文本。
- 沿用系统声音那一路的设置：实时字幕和片子不是同一件事，语言和服务会互相盖掉。
- 挤在实时字幕窗口里当一个模式：听和片子还是捆在一起。
- 跟着播放：90 分钟就要坐 90 分钟。边看边出字幕，在播放器里放，走系统声音。
- 按文件翻译收费：人是来听的，拖进来的片子用同一套识别。
- 多条音轨混在一起：分不清在译哪一路。
- 固定每几秒一条：一句会被拦腰截断。
- 必须整份成功才写文件：一段失败就丢掉已经译好的部分。
- 新文件换掉正在跑的：已经在跑的一份会被掐掉。
- 点停止立刻落盘：最后几段翻译还在路上，文件里会缺。
- 五份一起停：其余还在跑的会被牵连。
- 第 6 份排队：关掉窗口才发现后面还排着。
- 一份一扇窗口：五份片子叠成五扇。
- 起点加终点：要的是从某处听到结尾，不是截一段。
- 时间从零重计：SRT 对不上片子。
- 同一路径开两份：旁边只有一个 SRT，后写完的盖掉先写完的。
- 拖进来就从 0 开跑：设不了起点，多音轨也来不及选。
- 落盘后自动清行：段没法看。
- 退出时不等翻译：已经识别的段会丢。
- 同语也润色：这是听出来的字，不是一份要改写的文稿。
- 逐段确认遮盖：一部长片子会被确认框打断。
