# 实时字幕导出，不进历史

实时字幕一次会切出很多段。历史只收划词、剪贴板、截图识别和文件翻译，容量有限，一次会议就会把别的记录冲掉。要带走字幕时，从实时字幕窗口把当前内容另存为一份文本：开着的通道写在同一个文件里，每段是原文和这条通道当前显示的译文，只收已经译成的段。识别中的半句、还在翻译的段、失败的段不写。这份文件不写入历史，也不写入收藏。

## 考虑过

- 每段写成一条历史：之后能搜，但一次字幕就会占满历史。
- 只复制到剪贴板：留不住一场字幕。
- 只写译文：事后对不上原文。
