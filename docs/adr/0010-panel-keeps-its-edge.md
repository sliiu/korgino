# 翻译浮层长高时顶边不动，沉浸字幕往上长

译文和释义把浮层撑高之后，顶边留在第一次摆好的位置，多出来的高度往下长。拖过之后也留在拖到的地方。

沉浸字幕的底边留在用户放下的位置，多出来的高度往上长。上面的屏幕不够时，底边仍留在原地，字幕顶到屏幕上沿为止，不再把整块往下推。

窗口框由这一次测量决定，不再跟着 SwiftUI 的固有尺寸再改一次。

## 考虑过

- 每次按鼠标重新算原点：译文一高，浮层会翻到光标另一侧；拖走之后下一次测量又弹回去。
- 底边钉在光标上往上长：标题跟着往上移，已经开始读的原文离开原来的位置。
- 沉浸字幕高出屏幕时把整块下移：底边离开用户放下的位置，字幕往下跳。
