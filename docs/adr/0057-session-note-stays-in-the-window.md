# 一场笔记留在窗口里

实时字幕和媒体字幕可以把已经切好的段收成一场笔记。实时里一场是一条采集，媒体里一场是一份片子。哪一路能写笔记改由 `0059` 决定：一路一页。「只吃第一路」作废。译文优先用译成母语的那条绑定，没有就用第一条有译文的绑定，再没有就只用原文。

一页三段，正文用母语。前两段由一家 AI 写成，反复出现的词右边必须是送去的译文里已有的一段。没对上的句子从段里列出来。免费，用自己的密钥。写在本窗口里，可以复制。不进历史，不落成文件。整场一次送出，写不下就说明这场太长。发出前遮盖，回来填回，不弹确认。

清空、重新开始或去掉这份片子时，这一页收起。停下不收。还在等翻译的段不进。

## 考虑过

- 两条采集合成一场。
- 三段都交给模型。
- 太长就只总结最后一截，或分段再汇总。
- 记成文件，或放进 Pro。
- 遮盖之后不填回。
- 命中时先弹确认。这些字出字幕时已经静默发出去过。
- 译法、字幕上点词。这一轮不做。
