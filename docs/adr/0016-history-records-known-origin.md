# 历史只记下真正知道的来处

历史要能按来处找回去。划词记下当时的来源应用名，以及这个应用的包标识，好在列表里画出应用图标。应用名会随语言变，包标识不会；应用退出之后，图标仍靠包标识找到。文件记下路径，列表上显示文件名，原文里不再塞一行文件名。剪贴板和截图识别没有可靠的应用，不猜当时谁在前台，这些行也不画应用图标。取得方式本来就在，搜索也能对上划词、剪贴板、截图识别、文件。

文件的原文仍按别的记录那样留下开头一段。以前为了把文件名塞进原文，只留更短的一截。

收藏不带这些。收藏留下的是一条译文。

## 考虑过

- 剪贴板记下按下快捷键时的前台应用。人可能先在一个应用里复制，再切到别的地方才翻译，名字会对错。
- 截图记下选区底下的窗口。一块屏幕可以跨过几个窗口，认错了比没有更难找。
- 文件名继续写在原文开头。文件名找得到，原文的第一行却不是原文。
- 收藏也记下同样的来处。要找的是历史里的那次翻译，不是标星的那条译文。
- 只靠应用名去找图标。同名的应用会对错，换了界面语言也对不上。
