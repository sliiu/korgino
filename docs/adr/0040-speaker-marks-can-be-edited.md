# 标记抽出来改，删除等识别停下

已经认出的标记抽成一份列表。系统声音和麦克风各一份，例如 `[系统 1]`、`[系统 2]`。媒体每一份片子自己一份，例如 `[1]`、`[2]`。

一枚可以改成 `[张三]`。已有的段同步改，之后还被认成这个人的新段也用新标记。识别过程中就能改。几路译文用同一枚。

删掉一枚，或一次删光，要等识别停下。删掉的标记从已有段上拿掉。一次删光只清这一份列表。

导出仍按路，可选合并或分别。分别是一路两份，一份只有原文，一份只有译文。一开始用分别，之后记住上次的选择。标记写在原文行前。译文行不写标记。

## 考虑过

- 识别还在跑就删：新段又会把标记加回来。
- 只改之后的新段：已经切好的 `[系统 2]` 还留在列表里。
- 一次删光把系统声音和麦克风一起清掉：两条采集的人不是同一拨。
