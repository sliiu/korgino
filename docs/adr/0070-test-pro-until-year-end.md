# 测试包的 Pro 开到 2026 年底

## 结论

`./build.sh --release` 编译时带 `KORGI_TEST_PRO`，不带 `KORGI_DEV`。这份在 2026-12-31 当天结束前（本机时区）把 Pro 当作已解锁。从 2027-01-01 起回到免费档，购买仍按 `0062` 认。原来的 `--macos15` 和 `--macos26` 合成这一份，见 `0074`。

关于页写「测试中，Pro 开到 2026-12-31」。这段时间里不显示购买和免费档说明。

本机 `./build.sh` 仍是开发包，Pro 默认开着，没有这个日期。

## 为什么

要给 15.1 和 macOS 26 上的人试完整功能，又不能把开发开关打进去。开发开关默认一直当作已购买，没有到期日。

## 考虑过

- 测试包继续带 `KORGI_DEV`：关于页会出现「按免费版运行」，而且关掉之后没有到期这一说。
- 只给 macOS 15 的包：macOS 26 上试的人看到的仍是开发开关，没有到期日。两份测试包用同一个日期。
- 本机 `./build.sh` 也加上期限：每天开发还要能关掉 Pro，看免费档。期限只在 `--release`。
