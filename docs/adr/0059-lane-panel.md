# 一路一块面板

实时和媒体把每一路做成一块面板。字幕、标记、笔记和这一路的操作都在这块里。一场笔记是这一路的一页，只吃这一路已经切好的段。`0057` 里「只吃第一路」作废，笔记的其余规则还在。

窗口仍按采集分栏，媒体仍是一份片子一个播放器。栏里或播放器下面，一路一块，从上往下排。只有一路时也是一块。每块自己滚动，贴在底部才跟着新行。笔记打开时只有这块不跟。

面板里有识别引擎、绑定、这一路的字幕、标记、笔记、清空和移除。沉浸字幕只在实时的绑定上。分说话人和识别语言留在采集或片子上。一条采集一种语言，一份片子一种，按第一路的引擎收窄。删掉第一路之后，收窄跟着新的第一路。

导出仍是这条采集或这份片子点一次。媒体队列只留文件、进度、停止、导出和移除。语言、起点、音轨和开始在播放器下面、面板上面。

开始时收起设置。实时随时可以展开或收起，停下时自己展开。进行中面板只留路名、字幕、笔记和清空。媒体进行时和识别完，播放器下收成一行摘要；识别完可以点「调整设置」展开。设置都收起时整页不滚，面板分窗口的高度（见 `docs/design/2026-11-03-lane-panel-interaction.md`）。

清空只清这一路的字幕、半句和标记，并收起这一路的笔记。别的路不动。听着的时候清空，这一路从现在继续。停下不收笔记。重新开始或去掉片子，各路笔记都收起。

删掉一路时，字幕、标记和笔记一起删。停下，或片子不在识别，才能删。换引擎或换绑定不删已经切好的段。

标记一路一份。媒体不再整份片子共用一份。

## 考虑过

- 一场笔记仍是采集或片子上的一页，用选择器指定吃哪一路。
- 几路的字幕继续混在一条列表里，只是笔记按路写。
- 实时和媒体各做一套。
- 识别语言跟路。
- 进行中设置一直摊开。
- 媒体的语言和开始留在队列里。
- 删路后字幕留在数据里。
- 一换引擎就清掉这一路。
