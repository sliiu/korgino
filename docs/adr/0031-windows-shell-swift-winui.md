# Windows 壳用 Swift 和 WinUI 3

Windows 的窗口用 Swift 写，界面走 WinUI 3。Mac 的 SwiftUI 不参加这次编译，也不重写。窗口和动作与 Mac 对齐。画风见 `0034`。托盘、全局热键、划词、写回和系统声音仍按系统各接各的。

## 考虑过

- Flutter。界面自己绘制。菜单栏和不抢焦点的浮层要另接，引擎要改成 Dart。没有手机版要一起维护。
- Tauri。系统能力可以写在 Rust 里，翻译浮层和字幕落在网页视图里。
- MyGo。自带托盘、全局热键和不激活当前应用的浮层。读别的应用里的划选，以及系统声音，仍然要自己接。要换掉已经能用的 Mac 应用。
- 用 WinUI 默认外观。窗口对得上，两台电脑看起来不是同一个应用。画风改由 `0034` 规定。
