# 实时窗口按采集分栏，译成也按采集

「译成按采集」一句被 `0050-binding-is-service-and-language.md` 取代，改成每条绑定自己选语言。

实时字幕的窗口仍按采集分栏。栏里再按路分组。一段原文下面，是这条路绑上的翻译，各一行。沉浸字幕的开关在窗口上方，一块是一路加上一家翻译。第二块第一次出现在第一块上方，之后各自记住底边。

译成按采集。同一条采集上的几路译成同一种语言。识别按路。免费时两条采集用同一家默认识别和同一家默认翻译。

当次再加一路或再绑一家翻译，从下一句开始带上，已经切好的段不补译。拿掉一家，从下一句去掉，已经译好的留下，这块沉浸字幕关掉。这些加减不写回设置。媒体这份保持开跑时的那几路，直到这份结束。

## 考虑过

- 分栏改成翻译服务：系统声音和麦克风就不再并排。
- 译成按路：同一句要为每家各选一种目标语言。
- 中途启用就补译前面的段：一段话会再打一串已经听过的请求。
