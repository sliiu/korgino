# 本机打包用固定的自签名证书

## 结论

`build.sh` 用登录钥匙串里名为 “KorgiTranslate Dev” 的自签名代码签名证书签 `~/Applications/KorgiTranslate.app`。没有这张证书时，脚本第一次运行会自己建一张，只给 `codesign` 用。建不成才退回临时签名，并提示授权可能在下次打包后失效。

这只管本机开发包。公证包和商店包照 0006、0012 走各自的签名。

## 为什么

临时签名（`codesign -s -`）没有身份，系统隐私授权只能按这一次的签名哈希记。每次重新打包哈希都变，系统设置里“辅助功能”“输入监视”的开关看着还开着，对新包却不算数，划词和快捷翻译就读不到输入框。固定证书之后，系统按证书认这个应用，重新打包不用重新授权。

## 考虑过

- 保持临时签名，每次打包后手动关掉再打开授权。容易忘，表现成“授权了还是不行”。
- 用 Apple 开发者证书。这台机器上没有可用的签名身份。
