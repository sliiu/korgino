# 遮盖和涂抹不按引擎分开

翻译、释义、对话在发出去之前遮盖密钥和证件号，结果回来再填回。截图识别先让人涂掉一块，再拿涂过的图去识别。Apple 本地翻译和 Apple Vision 也走这两步，不因为字和图留在这台 Mac 上就换一条路。

文件里的图片和扫描 PDF 仍整页发给识图模型。识出来的文字在翻译前照样遮盖。历史、收藏、翻译浮层和字幕导出留原文。遮盖默认开着，偏好里可以关。遮盖自己出错时，这句话不发出去。

## 考虑过

- 只对会离开这台 Mac 的引擎遮盖、只对外部 OCR 涂抹：少一次确认，本地翻译也看不到占位符。选中的引擎一换，同一句话的保护就不一样，所以没有这么做。
