# 译文保持原文骨架

译文保持原文骨架，记号种类和空行数量都按原文装回。默认 AI 提示在划词、文件和实时字幕上遵守这一条；自定义系统提示整段替换默认提示，对话不套骨架。文件仍先抽成文本。

机翻分两档：Google Cloud、DeepL、Microsoft、LibreTranslate 走 HTML，不译片段标成不译；Apple、Google 免费、百度、有道、彩云、Lingva、MyMemory，以及走默认提示的 AI，把换行、空行、行首缩进、列表记号、标题记号、引用记号和表格竖线收成占位符，译文回来再按原样装回。引擎在占位符两边多加的空格会去掉。一块是标题、段落、列表项、单元格或引用，行内强调和链接留在句里，成块代码不送出。约 3000 字为一段，只在块之间切开，一段一次请求。装不回就用引擎返回的文本。字幕按句打包时不收换行，句与句的分界还是换行。

同语润色是全局开关，放在目标语言下面，默认开，只作用于划词和文件里走默认提示的 AI。关上则不发请求，译文就是原文。源语言判不出来就照常发。简体和繁体不算同语。实时字幕同语时，译文就是识别结果，不发出去。划词和文件里的机翻，同语也照常发。

## 考虑过

- 只保留空白，或把 docx 译完仍存成 docx。格式收成原文骨架，文件继续抽成文本。
- 机翻保持现状。有标签模式的用标签，其余本地拆装，骨架才覆盖每一家。
- 行内文字拆开单译。骨架更严，整句语序会散，所以按块送。
- 同语时一律不发、不润色。改成开关，默认照发并轻润色。
- 实时字幕也润色。半句会被改写，同语时改为识别结果本身。
