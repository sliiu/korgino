# 原文和译文到处都能朗读

以前只有文件翻译（只读译文）、实时字幕窗口和沉浸字幕能朗读。最常用的翻译浮层和词典没有朗读按钮。

现在这些地方都能读：

- 翻译浮层：原文框右下角（重新翻译按钮左边），每家译文的按钮排里（收藏左边）。按钮一直显示，不用悬停。
- 词典窗口和浮层里的词典：词条旁边。
- 文件翻译：原文标题栏也有，译文那个保留。
- 媒体字幕：每条原文、每条译文后面。

读原文用检测到的源语言，检测不到再按文本猜。媒体的原文用这份文件的识别语言。读译文用这条译文要译成的语言；目标语言是「自动」时，浮层按中译英、其它译简中推出来。词典里全是拉丁字母的词条按英文读，单个词按文本猜常猜错。

同一时间只读一段。每个按钮带自己的标记，只有正在读的那一个变成「停止」，出错提示也只挂在那一个上。点另一个按钮会停掉当前的，改读新的。

实时字幕、媒体字幕和会议记录里，每一位说话人可以指定一把声音。实时字幕和媒体字幕点字幕行上的说话人名字就能选，设置里的那一排也能选。没选就用设置里用来朗读的那一家，云端时菜单写明设置里的音色。每一家云端服务另有一项「设置里的」，用这一家现在填的音色，之后在设置里改了也跟着变；名单里单独点一把则钉死，不跟着变。系统语音按正在读的那种语言列。这把声音不在了，或那一家停用了，就退回默认，名字旁边写明。声音记在这一路上，会议记录跟着这一场留下。并入另一位或删掉这个人时，这把声音一起去掉。划词、词典和文件翻译没有说话人，仍只用默认的那一把。

## 考虑过

- 悬停卡片才出现朗读按钮：和复制、收藏放在一排更好找，浮层本来就不挤。
- 读原文一律按文本猜：短句常猜错，检测到的源语言更准。

## Windows

这一轮只改 Mac。Windows 要在同样的位置补上朗读按钮。
