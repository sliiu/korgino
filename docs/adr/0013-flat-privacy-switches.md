# 隐私开关平级，命中先确认

密钥、邮箱、手机号、身份证、银行卡，以及社会安全号、护照号、IBAN、生日、MAC、序列号、主目录用户名、用户名和主机名、公网 IP、云存储桶，在隐私里各自一个开关，互不嵌套。发出去之前换成占位符，结果回来再填回。命中时先把将要发出的内容给人看，确认后才发出。对话框里是替换之后的文本。同一段已经确认过，就不再问；文字变了会再问。

自定义词用逗号、分号或换行分开，短于两个字的不算。默认区分大小写。

社会安全号、护照号、IBAN、生日、MAC、序列号默认开。主目录用户名、用户名和主机名、公网 IP、云存储桶默认关。原来那个总开关如果关过，这些默认开着的类保持关。

Apple 本地翻译也走这一步。遮盖自己出错时，这句话不发出去。取消则不发出，实时字幕、释义和对话里不显示这条取消。

## 考虑过

- 个人信息收在一个总开关下面：少一行，但关邮箱就得连身份证一起关。
- 命中后直接发出、不给人看将要发出的内容：少一次打断，人不知道出去的是哪一句。
- 本地模型，以及命中后提醒或拦截：先前已经否掉。自定义词和确认是后来加上的，不把那两项 reopen。
