# 对话能选提问对象，Pro 能当次换模型

## 提问对象

对话以前只把原文和第一家出字的译文交给 AI。同时开了几家时，别的几家 AI 看不到，问「第二家为什么这么译」答不上。

现在对话顶上有一排提问对象：原文和每一家有译文的翻译服务。默认是原文和正在看的那一家（浮层是第一家出字的，文件窗口是选中的那一页）。点了从下一条消息起生效，对话不清空。至少留一项。

点过以后，换页或某家晚到的译文不再改回默认。换一段新的翻译（新划词、换标签、新文件）时回到默认。

交给 AI 时每一段写明是原文还是哪一家的译文，每段最多 6000 字，和以前一样。

## 当次模型

一份 AI 配置只有一个模型。Pro 可以在用到它的地方当次换一个，不写回设置。规则和 `0041` 的当次加家一样。

- 翻译浮层：每家 AI 名字旁边。换了只重出这一家，别的不动；等的时候又换了一次，先回来的那份丢掉。和临时加的家一样，新开一次浮层就清掉，重新翻译和换目标语言时留着。免费时只显示模型，不挂 Pro 标签，每家都挂太吵。
- 对话：模型菜单里，提供商下面列这一家的模型。这个窗口里选过的提供商和模型都留着，换一段新翻译也不丢。不再把对话里选的提供商写进文件翻译的默认。
- 文件翻译：译文旁边的模型下拉，对正在看的那一家。下一次翻译起生效，不自动重译。换过模型的那一页标签写成「名字 · 模型」。
- 实时字幕：每条绑定旁边。按 AI 配置算，同一家挂在几条绑定上一起换。和路网一样，退出应用就没了。
- 媒体字幕：每条绑定旁边，跟着这一份走（`0023`）。

列表来自偏好设置里拉取过的 `/models`，也可以在菜单里刷新。设置里的那个模型排在最前，选回它就等于没换。

免费时这些地方只显示设置里的模型，挂 Pro 标签。

## 考虑过

- 按绑定各记一个模型：同一家挂两条时可以不一样，但菜单要跟着绑定的键走，导出和沉浸字幕都认这个键，改动大，用处小。
- 文件窗口换模型就重译：长文件一次要花不少钱，翻译按钮已经在旁边。浮层一段话便宜，换了就重出。
- 记住 Pro 用户的选择：设置里会有两份模型，用户分不清哪份在用。
