# 长译文在浮层里滚动，浮层停在屏幕里

译文比浮层高时，标题和原文留在原处，下面的译文、链接和释义在剩下的高度里滚动。短译文仍然把浮层收成内容那么高。

浮层最高不超过屏幕可见区域。顶边照旧留在第一次摆好的位置；往下长出会超出屏幕时，停在屏幕底边，多出来的译文用滚动看。

单条译文不再自己锁在 220 点的小滚动区里。那一块和窗口裁切叠在一起时，看得见的字滚不动。

## 考虑过

- 每条译文各自滚动：两条叠起来仍然高出窗口，窗口把滚动区域裁掉，滚动手势落在裁切外面。
- 窗口继续跟着译文长高：长文直接画出屏幕，上下都被裁掉。
- 用一个总会占满提议高度的滚动区：一行译文也会把浮层撑到最高。
