# 母语和目标语言对翻

设置里的母语和目标语言是一对。划词、剪贴板、截图识别、快捷翻译、文件翻译在这对之间对翻：原文是母语就译成目标语言，原文是目标语言就译成母语。第三种语言，以及语言检测失败，译成母语。简体和繁体算两种语言。两种可以选成同一种。这时走默认提示的 AI 按同语润色轻改措辞；普通翻译译不了就留下原文。

母语用来读译文，不是应用语言。两个都是具体语言，没有「自动」。母语默认跟系统语言。目标语言默认是 English，不因为母语是 English 就改成别的。系统语言已经是 English 时，母语默认简体中文，目标语言仍是 English。

已经存过的目标语言：自动改成 English，某种具体语言沿用。没存过的用 English。母语按上面的默认。

浮层上的语言菜单是这一页的当前目标语言，文件窗口是这个窗口的，都不写回设置。新的一页从设置或来源应用的目标语言开始。文件窗口关掉再开，回到设置。

某个来源应用可以有自己的目标语言。划词开页时用它当当前目标语言，快捷翻译用它和母语对翻，语音翻译和语音传译把它当作译成、不对翻。留空则用设置里的目标语言。

实时字幕和媒体字幕不走这对。译成去掉「自动」，只留具体语言。已经存成自动的，改成目标语言。新开的绑定第一次用目标语言。

## 考虑过

- 第三种语言译成目标语言。看不懂的外语应落到母语。
- 留下「一律译成某一种」。翻译只留对翻。
- 实时字幕和语音也对翻。一句里夹了母语会来回跳。
- 系统是 English 时把目标语言改成简体中文。目标语言的默认固定是 English，撞上时改母语。
- 当前目标语言写回设置。浮层和文件窗口只改这一次。
- 当前目标语言不能和母语相同。相同的时候，AI 轻润色，普通翻译译不了就留原文。
- 按应用只改快捷翻译。这是这个应用的目标语言，划词和语音也用。
- 字幕保留「自动」。自动是写死的中英，和这对不是一回事。
