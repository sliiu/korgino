# 写回只盖划词时的选区

划词拿到的是另一个应用里的选区，写回也落回那里。剪贴板没有原来的位置。文件翻译已经另存一份译文。翻译浮层里的原文格只是这次翻译的输入。

写回是翻译浮层里的一个动作。划词来的每条译文旁边有一个，挂在这次划词上的每条助手回复旁边也有一个。点哪条，就盖哪条。浮层在前台时，⌘1 到 ⌘9 按从上到下的顺序写回第几家供应商的译文。没有译文的那一家按了不动。超过九家的没有快捷键。数字标号默认不出现，按住 ⌘ 满一秒才显示，松开就收起。快捷键本身不用等这一秒。你发出的那句和释义没有写回。不自动盖，也不另设快捷键。点写回就是确认，不再弹一次。

盖进去的都是读出来的纯文本。译文去掉标记。回复盖整条，说明也在里面，不从回复里抽一句。复制回复仍保存原始内容。剪贴板不动。读出来是空的，就不盖。

来源应用里的选区必须仍是这次划词抓到的那句原文。对不上就停住，浮层里说明，不去盖现在选中的别的字。浮层里改过原文再翻译，不改变要核对的那句。对话回复盖的也是这句。固定浮层时每次划词各记各的原文。换标签会清掉对话，所以屏幕上的回复只属于当前这次。

来源接不住时也停住并说明，译文和回复还留在浮层里。写回前先把焦点还给来源应用，再核对选区仍是那句原文。辅助功能能直接改就改。改不了时，只在核对成功、并且焦点已经回到那个应用之后才粘贴，粘贴完把剪贴板放回去。对不上，或焦点没回去，就不粘贴。网页、PDF、只读文字仍然停住。

写回成功就结束这一次，没发出去的对话草稿也一起结束。只有一个标签时，关掉浮层，焦点回到来源应用。还有别的标签时，别的留下。没固定的浮层，下一次点来源应用仍会整窗关掉。要留住别的标签，用固定。

写回跟着划词，不另收费。剪贴板和截图识别没有选区，译文和回复都不出现写回。

## 考虑过

- 改剪贴板里的原文。翻译剪贴板没有可盖的选区。
- 改文件翻译的那份文件。产物已经是另一份译文。
- 改翻译浮层上面那格原文。那不是用户要留下译文的地方。
- 译文一出来就自动盖掉。译文可能是错的，也可以同时开多家，盖错了常常撤不回来。
- 再加一条「译完就盖」的快捷键。划词快捷键已经会打开翻译浮层。
- 选区对不上也照样粘贴。固定浮层可以连着划好几次，前一次会把后一次的选区盖掉。
- 把模型返回的原文原样写入。目的地是邮件、备忘录、输入框，标记会留下来。
- 不核对就模拟粘贴。浮层已经抢走焦点，粘贴可能落进别的输入框。后来改成先还焦点、核对原文，才允许这一次粘贴。
- 对话回复和释义都不写回。回复常常就是用户要留下的那句。释义是词条，不是要盖回去的文字。
- 从回复里只抽出一句再盖。说明和正文混在一起时会抽错。
- 回复写回成功后留下对话。同一次翻译的两个按钮会一个关、一个不关。
- 还有别的标签时，写回成功后不还焦点，或点外面也不关。固定本来就是「点外面不关」，不再加一种例外。
