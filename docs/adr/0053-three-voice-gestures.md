# 按住 Fn 走当前语音模式，快捷键只切模式

原先的语音输入是按住 Fn 这一条。翻译只是设置里的「同时翻译」。没有能写的输入框，这一条不会开始。

改成三种语音模式，共用同一页的识别引擎、语言和翻译服务。开关去掉。按住 Fn 走当前这一条，松开才结束。快捷键不开始听，只把模式切到某一条。切的时候出提示；按住 Fn 时提示上也写着当前模式。上次选的模式留着，默认是语音识别。

- 语音识别：松开后写下听到的字。按住时浮层上是听到的字。
- 语音翻译：按住时译文就出现在浮层上，松开后写入。
- 语音传译：按住时浮层上出译文，说完的句子当时就读。松开后读完还没读的部分。不写进输入框。

识别和翻译只写回按住时的那个应用，而且松开时它还在前台。中途换了应用就不写。麦克风没开之前胶囊写「准备中」，不写「在听」。翻译失败时听到的字仍记进历史。

识别和翻译写得进当时的输入框就写进去。三条都不进剪贴板，都记进历史。写进了输入框的识别和翻译，历史里记下那个应用；写不进的、以及传译，不猜前台应用（`0016`）。语音识别在历史里的原文是听到的字，译文空着。语音翻译和语音传译记下听到的字和译文。传译不读还没断句的尾巴，免得把正在改的词读出去。

默认快捷键是 ⌥⇧R 语音识别、⌥⇧T 语音翻译、⌥⇧S 语音传译，都可以改。菜单里当前这条打勾。「按住 Fn」关掉之后，Fn 和这三把键都不生效。切模式时胶囊写出模式名，停大约一秒。按住 Fn 时胶囊写「在听 · 当前模式」。按住中途按别的键取消，这三把键也算。

这一轮只改 Mac。

## 考虑过

- 三把快捷键各自按住触发。Fn 已经是说话的手势，再记三套按住会打架。快捷键只负责切模式。
- 留着「同时翻译」开关。开关和模式各说各的。
- 写不进输入框就进剪贴板。剪贴板里常常是刚复制的东西，盖掉容易误事。历史留得住，也不动剪贴板。
- 传译也写进输入框。这条多半没有输入框，对方要听到的是译文。
- 整句说完再读。人还按着的时候译文不出来。按住时就出译文，断了句的部分当时读。
