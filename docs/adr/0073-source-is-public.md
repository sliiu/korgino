# 源码公开

## 结论

源码放在公开仓库 `sliiu/korgino`。原来的私有仓库 `sliiu/korgino-code` 于 2026-11-11 改名并设为公开，旧地址自动跳转到新地址。

收费方式改成商店应用免费加内购。安装包不再发到另一个仓库，推送 `v*` 标签后流水线直接在本仓库建 Release。流水线用 `github.token`，不再用 `KORGINO_RELEASES_TOKEN`。应用里的检查更新仍读 `sliiu/korgino`，地址没变。

这个决定替换 `0071`。`0071` 里「源码要私有」不再成立。

## 考虑过

- 另建一个公开仓库再推过去：改名保留全部历史，旧地址自动跳转，已有的克隆不用改。
- 继续用一把 token 往别的仓库发布：源码和安装包在同一个仓库，流水线自带的 token 就够。
