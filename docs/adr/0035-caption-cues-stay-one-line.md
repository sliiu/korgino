# 字幕按一行来切

取代 `0019` 里「说到一句的收束、并且够长，才成为一段」。识别结果经常没有句号，一句又能说很久。按整句切，媒体字幕一条就铺满列表。

一条字幕不按固定字数切。先看这句话说了多久，再看这行字在屏幕上有多宽。停顿大约半秒，或一句话说完，就换一条。一句话超过大约 4 秒，或这行字宽到屏幕的一半左右，就在逗号处提前切开。宽度取字幕窗口和屏幕里更窄的那一边，只用其中大约七成，所以字幕不会贴到屏幕两边。

识别给的是每个词的起止，不是每个字。中文词再把这段时间均分到每个字上，标点跟着前一个字。英文词不拆开。一条的起点是第一个字的时间再提前 0.2 秒，终点仍是最后一个字说完的时间。

说话人变了就换一条。实时字幕用同一套宽度。没说完的半句仍留在正在识别的那一行，这一行本身也不超过屏幕上留给字幕的宽度。停下之后，这一行再落成一段。

## 考虑过

- 维持整句一段。没有句号时一条就是一整段识别结果。
- 固定每几个字一条。窗口变宽、话说得慢，这条数都不对。
- 固定每几秒一条。一句话会在词的中间被截断。
- 只把界面折行，段仍按整句存。导出的 SRT 还是一条铺满。
