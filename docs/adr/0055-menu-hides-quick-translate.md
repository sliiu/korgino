# 快捷翻译不进菜单，语音模式在菜单栏上

快捷翻译和撤销快捷翻译仍由快捷键触发，不出现在菜单栏菜单里。连按空格画进菜单那一行因此也不再画。

三条语音模式收进一个二级菜单，用来切换。这一行一直在。

菜单栏图标旁边要不要写出当前模式，在「功能 › 语音」里开关，而且只有语音开着才写。语音关掉之后，菜单栏不写模式名，菜单里的语音模式也收起。点菜单栏仍然只打开菜单。

## 考虑过

- 快捷翻译留在菜单里，只是不画快捷键。菜单会多两行用不到的入口，触发本来就是手势。
- 三条语音模式仍平铺在菜单顶上。当前是哪一条要看勾，菜单栏本身看不出来。
- 点菜单栏上的模式名来开关「按住 Fn」。那是听写的总开关，不是「显不显示」的开关。
- 语音关了还在菜单栏留着模式名。关了就没有当前模式可看。
