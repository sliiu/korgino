# 声纹模型不进安装包，第一次要用时再下载

分说话人原来只看音高和过零率，两个人声音接近就分不开，最多 5 人。改用声纹模型：WeSpeaker ResNet34-LM（VoxCeleb，CC BY 4.0），由 wquguru/cicada 转成 Core ML。每段说完后在本机取一个声纹，按余弦相似度归到已有的人或新开一位，最多 12 人。

## 结论

照 `0033` 的问法：在实时字幕「分说话人」那一行点「用声纹分得更准…」，问下载（约 12 MB）、从文件导入或取消。下载先试 Cloudflare R2，失败或校验不通过再试阿里云 OSS，同一个文件。核对 SHA-256 再解压，在本机编译一次，放在 `~/Library/Application Support/KorgiTranslate/Models/Voiceprint/`。不会自己联网。

装好以后，下一次开始起，实时字幕按声纹给每一段定说话人；不到 2 秒的段只能归到已有的人。没装、装坏了或这一段太短太静时，仍用原来的音色判断，字幕不受影响。会议记录里有录音的一路可以「按声音重新分说话人」，改过的名字会清掉。

关于页写明模型来源和协议。

媒体字幕识别时仍按音色给号，字幕先出来。模型装好了，这一份的识别结束后按声纹把每一路重新分一次，改过的名字清掉，和会议记录里「按声音重新分说话人」同一套。没装模型、装坏了或没分出来，就留着音色给的号。

## 为什么

`0003` 的用户在国内，GitHub 慢；R2 海外快，OSS 国内快。大多数人不分说话人也能用，不该每次安装都多带 12 MB。

## 考虑过

- 打进安装包：每个人都下，商店包审核也多一样东西。
- 直接引用 Cicada 仓库里的文件：别人的仓库，路径随时会变。
- 不用模型，改进音色特征（MFCC 等）：不加体积，但准确度差得多。
- 用 GPU 跑：每段长短不一，GPU 每次都要重新编译，反而更慢。用 CPU，4 秒的段约 7 毫秒。
