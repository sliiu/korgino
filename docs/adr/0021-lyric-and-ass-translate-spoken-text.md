# 已经写好的歌词和字幕只译台词

文件翻译里的 `.lrc`、`.srt`、`.vtt`、`.ass`、`.ssa` 只译能唱、能读的字。序号、时间、歌词元数据和样式代码留在原处。行内的逐字时间拿掉，整行一起译；行的起止时间，以及位置、颜色、字体留着。每个时间点上只放译文，原文还在原来那份文件里。一句译失败，这一句留原文，其余照译。一条台词都认不出时，整份当文本译。认得出一部分时，认不出的行原样留着。译文另存成同格式的 `原名.translated.srt` 这一类文件。这仍是文件翻译：原文已经是字。整份当文本会把时间轴译坏，播放器打不开。

## 考虑过

- 只有 `.lrc`、`.ass`、`.ssa` 这样处理，`.srt` 和 `.vtt` 继续整份当文本。四种字幕会有两种结果，后两种仍然对不上播放器。
- 整份当文本。时间码不在原文骨架里。
- 同一时间点叠上原文和译文。位置和换行是按原文排的，再叠一行会溢出；媒体字幕才是上面原文、下面译文。
- 一句失败就整份停下，或把这一句从译文文件里拿掉。原文件还在，拿掉一句会在那个时间点空掉。
- 逐字时间按音节留下。译文的字数对不上拍子，句子会被切碎。
- 一条都认不出就报错。坏文件或误用扩展名的文章会译不了。
