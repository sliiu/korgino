# Windows 的本地识别、朗读和截图各占一行

细化 `0030`。识别是多语言 Whisper base，大约 150MB，界面上叫「离线识别」。不放进安装包，第一次要用时再下载，见 `0033`。实时字幕、媒体字幕和麦克风听写的免费本地识别都用它。不另做语音分析那一行。偏好设置里的「本地 Whisper」仍是用户自己开的接口。

朗读用 Windows 自带语音合成，这一行叫「系统语音」。截图识别用 Windows 自带 OCR，这一行叫「系统 OCR」。云端识别、云端朗读和云端 OCR 不动。

## 考虑过

- 把这份模型也叫「本地 Whisper」。这个名字已经指本机开的兼容接口。
- 用 tiny。听外语不够。用 small。大约再多 300MB，超出小型。
