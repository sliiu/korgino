# 实时字幕导出一份带时间的 SRT

系统声音和麦克风从同一次开始共用一条时间轴，不另存声音。导出一份 SRT：原文行前标 `[系统]` 或 `[麦克风]`，这一路说话人多于一个时写成 `[系统 2]`。时间重叠的两条都留，按开始时间排。两路译成不同语言时，各写各的译文。原来的 txt 去掉。再点开始会清掉上一轮已经切好的段，时间从零重计。

## 考虑过

- 两份 SRT：就不是一起导出。
- 重叠合成一条：一句长、一句短时对不齐。
- 另存混音：和媒体字幕重复，也分不开两路。
- 继续留 txt：没有时间，对不上这次收听。
- 两路合成同一个目标语言：麦克风和系统声音本来就不是同一场翻译。
