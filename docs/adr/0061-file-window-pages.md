# 文件窗口的译文按页，一页一家、一种语言

接 `0041`：文件翻译免费只跑默认一家，Pro 可以多家。

翻译文件窗口的译文区是几页，上面一排标签切换。一页只有一家翻译服务，整页都是它的译文。页上自己选服务、目标语言，AI 还能选模型。同一家可以开几页，各译成不同的语言。

起点是设置里文件翻译的那几家，一家一页，目标语言用设置里的。没动过页、也还没出译文时，页跟着设置变。

- 工具栏的翻译和重新翻译：每一页都翻。
- 改了一页的服务、语言或模型：只有这一页的译文作废。窗口里已经翻过的话，马上重翻这一页。
- 加号新开一页：先挑一家，语言跟正在看的那一页。已经翻过就马上翻这一页。
- 标签上的叉关掉这一页，至少留一页。
- 历史里每页记一条，名字后面带目标语言。

这些只在这个窗口里，不写回设置。

免费只有一页，服务是默认那一家，目标语言可以换。加号挂 Pro 标签。Pro 到期时只留第一页，换回默认那一家。

## 考虑过

- 下拉里勾几家，结果按家并排：一家只能译成一种语言，想要同一家的中文和日文要开两次窗口。
- 窗口只有一个目标语言：几家对照时都得译成同一种。
- 可折叠列表和标签两种排法：一页一家之后，列表里要再摆每一家的语言和模型，挤不下。
