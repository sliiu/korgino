# Windows 共用引擎，另写壳

Windows 版和 Mac 是同一个产品，功能对齐菜单里的全部项。翻译请求、遮盖、原文骨架、历史、收藏、字幕时间轴和网络会话留在同一份 Swift 里，两边一起编。界面、划词、写回、系统声音、热键、截图和本地的识别与 OCR 各写各的。Mac 的 SwiftUI 保持原样。第一版在自己的电脑上跑，不认 Mac 公证包的钥匙，也不卖。这台电脑的包沿用开发开关，默认当作已购买。Mac 上两份包各认各的购买，见 `0062`。

## 考虑过

- 换成一套跨平台界面，两边编同一份界面。现在的 Mac 界面已经定了，SwiftUI 也没有 Windows 目标。系统声音、划词和写回仍然得各接各的系统。
- 第一版只做实时字幕和划词。菜单里的其余项也要有。
