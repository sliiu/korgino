# 一轮界面修补，不换画风

走查记录在 `docs/design/2026-10-31-ui-pass-audit.md`。只修那里列出的问题。配色、字号、圆角和各窗口的结构照 `0034` 不变。

- 设置里的开关换成原生小号开关。分段药丸只留给多选一，例如外观。
- 设置保留顶部分页和子侧栏。只有两行的子页并进相邻的子页。
- 状态写法统一：缺东西用次要色文字加一个小橙点，例如「未填密钥」；默认那家写「默认」，别的家悬停才出「设为默认」按钮。
- 实时窗口两栏用同一套行，左右对齐。「音色」改叫「区分说话人」，两端写「少分」「多分」，不显示数值。默认高度放得下两栏。
- 沉浸字幕悬停条的字不小于 11 磅，按钮不小于 20×20。字幕只留黑底，不叠阴影。
- 语音输入按住 Fn 时显示「在听」：麦克风、五根跟着电平跳的竖条、已识别的字。松开才是「翻译中」。扫光只留给快捷翻译（`0024`）。
- 翻译浮层标题写语言名，不写代码。
- 翻译文件的「翻译」按钮去掉 `sparkles`。
- 全应用不再用 7–8 磅粗体图标。

## 落地时定下的细节

- 「功能 › 查词和记录」并进「翻译」页，成为页尾的「查词」一节。快捷键页里查词和历史的快捷键不动。
- 浮层标题的方向写成「English → 简体中文」，源语言不确定时写「自动检测」。不再在后面补「（自动）」，右上角的目标语言选择已经写了。这串字也进历史，只是给人看的。
- 语音输入松开 Fn 后先写「识别中」，要翻译时再写「翻译中」。两种都用小转圈，不用扫光。
- 历史里的占位符不是历史的问题：有的引擎（MyMemory）把 `⟦§4⟧` 改成 `⟦ § 4⟧`、`⟦ § 4您⟧`，填回时认不出，浮层和历史里就都露了出来。现在填回前先把这种写坏的占位符拼回原样，夹进去的字挪到后面；仍然认不出的占位符直接删掉。
- 「你好」认成繁体：不再信 `NLLanguageRecognizer` 对简繁的判断，改成把原文转成简体，字变了才算繁体。
- 历史去重：同一来源应用（没有应用时按同一种翻译方式）、同一原文，60 秒内只留最新一条。

## Windows

这一轮只改 Mac。Windows 待跟进的是：原生开关、状态写法、实时窗口的行和绑定、沉浸字幕悬停条、语音输入的「在听」、导出表（`0048`）。浮层方向写语言名、占位符修复和历史去重在共享的 `Engine/` 里，Windows 自动带上；简繁判断在 Mac 专有的 `AppleLanguageDetect`，Windows 要另做同样的判断。

## 考虑过

- 整体换画风：现在的底子是对的，还要推翻 `0034` 和 Windows 对齐的那套数值。
- 设置改成一列侧栏：要重排整个偏好设置，收益不抵风险。
