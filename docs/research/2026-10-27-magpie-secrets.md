# magpie 怎样保护密钥和私密信息

看的是 [yetone/magpie](https://github.com/yetone/magpie) `b7d5a97`（2026-10-27）。它把两件事分开做：自己保存的密钥，和请求离开这台电脑之前正文里的密钥。

## 自己保存的密钥

供应商 API key、网关发给别人用的 key、GitHub token、同步用的口令，都是明文 JSON，文件权限 `0600`，目录对登录用户可读。

| 放在哪 | 里面有什么 |
| :-- | :-- |
| `providers.json` | 供应商 API key、`secretAccessKey`、自定义 header 里的密钥。`writePrivate` 用 `0600` 原子替换 |
| `caller-keys.json` | 局域网共享用的网关 key。列表接口把 secret 清空，只留末尾几位；比对用常量时间 |
| `settings.json` | `GitHubToken`、旧版局域网 key。GitHub token 只发往 `api.github.com`，错误信息里不出现 token 本身 |
| `sync.json` | WebDAV / S3 / GitHub 的密码，以及给备份加密的口令 |
| `redact.key` | 32 字节 HMAC 密钥，用来让同一个值每次变成同一个占位符。它推不出原文 |

订阅登录（Claude、Codex 等）从各 agent 自己的文件或钥匙串里读。设置里可以关掉「发现订阅账号」，一次运行也可以用 `MAGPIE_NO_ACCOUNTS=1` 关掉。备份和同步不带走这些登录；每台机器自己签。

界面列表不回传密钥。`SecretAccessKey` 不发给窗口。

## 离开这台电脑之前

Settings → Privacy 的脱敏默认关。打开之后，网关在请求发给供应商之前替换正文，回复里再填回去。agent 和本地文件仍是原文。

找得到的东西分三层：

- 规则能确定的：私钥块、各家 API key 的前缀（`sk-`、`AIza`、`ghp_`、`AKIA` 等）、JWT、连接串里的密码、`.env` 里叫 password / secret / token / api key 的赋值，以及中文、日文、韩文里「密码是…」「密钥为…」这种写法。邮箱、手机号、身份证、银行卡要校验（身份证校验位、Luhn）。示例邮箱（`example.com`、`.test`）和 `git@` 远程地址留下。
- 用户自己的词和正则。
- 可选的本机模型，用来找规则抓不到的姓名、地址、孤立密码。默认是约 39 MB 的 AstrLink Guard；也可以下 OpenAI 的 Privacy Filter（约 1.6 GB，校验 sha256 后才保存设置）。模型跑不起来时请求不发出。用户名目录、公网 IP 这类几乎每次写代码都会出现的类别，默认关。

同一个值每次都是同一个占位符，形如 `{{API_KEY_k3v9x2mq}}`。占位符是 HMAC-SHA256 的前 8 个 base32 字符，密钥在 `redact.key`。对话、供应商的 prompt cache、思考块签名因此还对得上。原文到占位符的表只在内存里，上限 20 万条，重启就丢；下一次请求再带上同样的值，会算出同一个占位符。一个值被遮过一次，后面不管周围是什么字，再出现都会被遮。

流式回复也会填回，包括模型少写了花括号或改了大小写的情况。工具参数按 JSON 再转义一次。供应商签过名的思考块不改写，避免签名对不上。

三种处置：遮住（默认）、只警告仍原文发出、挡住。挡住的请求回 400，再发还是挡。脱敏开着但插件没接上，或脱敏自己 panic，回 503，正文不发出。

记录写在 `~/.config/magpie/masking/`，只留种类、发现方式、占位符、前缀或首字、长度。原文不落盘。供应商实际收到的正文只留在内存里，给最近若干条请求回看。

还可以把密钥换成同长度、同前缀的假密钥，给会检查 `sk-` 这种形状的工具用。假密钥同样能在回复里换回真的。

指向本机或局域网的供应商（Ollama、LM Studio）可以单独跳过脱敏。地址后来改成公网供应商时，这条跳过失效。

请求归档另算。归档默认关。打开后，请求和响应在写入用户自己的 S3，或本机 `RequestArchiveLocal` 目录之前，用 `Scrub` 把密钥换成 `[REDACTED:KIND]`。这次替换不进占位符表，也填不回来。名为 Authorization、cookie、key 的头和字段整段换成 `[REDACTED]`。

## 备份和多机同步

备份是一个 JSON 信封：`PBKDF2-SHA256`（60 万次）推出密钥，`AES-256-GCM` 加密正文。盐和 nonce 在信封里，信封字段本身算进 GCM 的附加数据。可以整包不带密钥；不带时，名字像密钥的 header 和环境变量值会被清空。

同步到 GitHub 时，仓库必须是私有的。口令不能和 GitHub token 相同，也不能和服务器密码相同：服务器拿得到密码，就能打开备份。历史里会留下旧的密文。订阅登录不进备份。

## 和 KorgiTranslate 现在的做法

KorgiTranslate 的 API key 在钥匙串里，服务名 `com.sliiu.KorgiTranslate`，`kSecAttrAccessibleWhenUnlocked`（`Sources/Keychain.swift`）。magpie 把自己的供应商 key 放在 `0600` 的 JSON 里。

KorgiTranslate 把划词、剪贴板、截图识别和实时字幕的原文整段发给翻译服务，发出前不做替换。历史、收藏和字幕导出会把原文留下来。

## 决定

要做两件事。

- **遮盖**：翻译请求离开这台 Mac 之前，把原文里的密钥换成占位符，译文回来再填回。API key 仍放在钥匙串。
- **涂抹**：截图选区里把一块画面涂掉，再识别。Apple Vision 和外部 OCR 都一样。涂掉的像素认不到。

术语记在 `GLOSSARY.md`。遮盖和涂抹不按引擎分开，记在 `docs/adr/0009-mask-and-smear-for-every-engine.md`。涂抹放在选区里，记在 `docs/adr/0010-smear-inside-selection.md`。

定下来的范围：

- 划词、剪贴板、截图识别出的文字、文件正文、实时字幕、对话、释义都遮盖，Apple 本地翻译也遮盖。
- 规则只认 API key、私钥、JWT、邮箱、手机号、身份证、银行卡，以及「密码是…」「密钥为…」这种写法。默认开，偏好里可关。不下载本机模型，不加自定义词。遮盖出错就不发这句。
- 每次截图（含 Apple Vision）都在选区里涂，涂在冻住的画面上。涂过的地方用实色盖住，选区挪开也还盖着原来的像素。点识别才继续。二维码在涂过的图上认。
- 文件里的图片和扫描 PDF 不涂。识出的文字在翻译前遮盖。
- 历史、收藏、翻译浮层、字幕导出留原文。


## 隐私页里的本地脱敏

2026-10-27 对照的是 [本地脱敏](https://usemagpie.ai/docs/zh/masking)（仓库 `11dcc74` 的 `site/public/docs/zh/masking.html`）。设置 → 隐私里这一块和「magpie 自己会发出什么」不是一页事。整页默认关。

怎么找：规则默认开。本地模型另开，默认关，可选 AstrLink Guard（约 39 MB）或更大的 Privacy Filter。模型只在密钥或个人信息已经打开时才跑。

要遮什么，三组开关：

- 脱敏密钥：私钥、各家 API key、JWT、URL 里的密码、`KEY=值`、自定义规则。
- 脱敏个人信息：邮箱、大陆手机号、校验过的身份证和银行卡。打开后还有细项。默认开着的是美国社会安全号、护照号（旁边有 passport / 护照）、IBAN、生日（旁边有 birthday / 生日，且早于一年前）、MAC、序列号。默认关着的是主目录用户名、`user@host`、公网 IP、云存储桶。文档写明这些是 Agent 几乎每个请求都会带的。
- 脱敏词，和自定义脱敏规则（前缀或正则）。另有从不脱敏，整段匹配则原样发出。

发现敏感值时，每种类型可选脱敏（默认，换成占位符）、提醒（原样发出）或拦截（400，请求不发出，报错里不带原值）。脱敏跑不起来则 503，不退回成明文。占位符是类型加 8 位哈希，同一值每次相同，原值只在内存里。

图片和文件数据不遮。思考块原样。模型 ID、工具名不遮。

KorgiTranslate 把密钥和每一类个人信息做成隐私里的平级开关，不嵌套。发出去之前替换，结果回来再还原。社会安全号、护照号、IBAN、生日、MAC、序列号默认开；主目录用户名、用户名和主机名、公网 IP、云存储桶默认关。原来的总开关如果关过，这些默认开着的类保持关。自定义按条添加，每条是普通词或正则，可以指定替换成什么。留空则用占位符。命中时先显示将要发出的内容，确认后才发出。不放本地模型，也不做提醒或拦截。这些开关在设置里单独的「隐私」标签，不放在通用里。见 ADR 0013、0014、0015。
