# style-audit · Korgino

决策：**default**。用户 2026-11-07 选择「默认暖白／炭黑」。宣传字卡、背景和外层容器用 `assets/fallback/` 的 tokens；功能镜头按产品自己的界面重搭，保留图标与深色窗口底这两个品牌识别点。

## 1. 色板（产品，仅用于功能镜头内部）

来源 `Sources/Theme.swift`：

- 窗口底 `windowFill`：浅 `#F4F4F6`，深 `#1C1C20`
- 卡片 `cardFill`：浅 `#FFFFFF`，深 `#2A2A2F`
- 分隔线 `hairline`：primary 8% 透明
- 图标（`Assets/AppIcon.svg`）：气泡底 `#A594FF` → `#6A58E4`，毛色 `#FFC56A` → `#F0943E`，脸 `#FFF7F0`，右下角青色圆点 `#3ED0C4`

产品有完整的浅色与深色主题。本片走暖白纸面，功能镜头用**浅色**界面，让它贴在纸上。

## 2. 字体

产品全部用系统字体（`.font(.system(...))`），正文 12–15px，时间码用等宽。
宣传标题按 default 样式：英文 Georgia，中文 PingFang SC，两者分开指定。

## 3. 空间与形状

`Theme.panelRadius = 16`，`cardRadius = 10`，插件条与语音胶囊用全圆角。浮层带 0.5px 描边和顶部高光描边，底是 `.regularMaterial` 磨砂。

## 4. 品牌

完整图标：`Assets/AppIcon.svg`（柯基狗头 + 右下角青色圆点）。没有横向 logo。菜单栏模板 `Assets/MenuBarTemplate.png` 是单色气泡，本片不用。

## 5. 镜头适配

产品是原生 SwiftUI，浏览器接不进真实组件（没有 Web 构建）。替代：按上面的色、圆角、字号和结构，在浏览器里重搭三个镜头用到的界面，并放大到视频尺度（正文 15px × 2 = 30px）。阻碍记在此：没有可复用的 DOM 组件，重搭保真度依赖本文件的测量。

## 6. 母题候选

- 图标的几何：两只竖耳、一张圆脸、右下角一颗青色圆点（气泡）。
- 核心界面：浮在选区上的翻译浮层、浮在选区上的插件条、贴在屏幕上的语音胶囊、一路一块的字幕面板。
- 数据形态：一句话变成另一句话；一段声音变成一行字幕。
- 名字的字面意象：柯基（corgi），矮脚、竖耳、跟着人走。
