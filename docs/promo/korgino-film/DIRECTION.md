# DIRECTION · Korgino

## 产品气质

Korgino 是菜单栏里的翻译，人在别的应用里干活时顺手用它：划一段字、按住 Fn 说一句、开会时看字幕。感觉是安静、贴身、不打断。设计语言见 `evidence/style-audit.md`。

母题：浮层。产品所有的动作都是「从一段内容上浮出另一段」。图标右下角那颗青色圆点是它唯一的点缀。

## 三个方向

| 轴 | A 纸面编辑 | B 深色舞台 | C 一天的使用 |
|---|---|---|---|
| 底色与光 | 暖白纸面 + 墨线 | 近黑 + 紫青光晕 | 真实桌面截图 |
| 字体声音 | 衬线大字 | 超细无衬线 | 产品自己的系统字体 |
| 母题来源 | 界面本身 | 图标几何 | 用户场景 |
| 镜头语言 | 平面排版，界面当插图 | 3D 机身 + 录屏 | 录屏质感，一镜到底 |
| 转场 | 硬切，字留下 | 穿越缩放 | 匹配剪辑 |
| 节奏 | 发布会式从容 | 预告片式紧凑 | 安静叙事 |
| 声音 | 钢琴与轻打击 | 电子脉冲 | 环境声铺底 |

## 选定：A 纸面编辑

理由：用户选了默认暖白／炭黑；上一支发布片已经是 B（深色、机身、录屏、预告片节奏，见 `docs/promo/launch-film.md`），A 在底色、镜头语言、节奏三个轴上与它错开。产品自己的浅色界面贴在暖白纸上，深色窗口底不用。

## 专属手法

1. 因为产品的每个动作都是从一段内容上浮出结果，所以开场让一句中文落在纸上，译文从它下面长出来，而不是用 logo 开场。
2. 因为产品活在别的应用里而不是自己的窗口里，所以功能镜头里的界面都浮在一句原文之上，没有窗口边框和桌面。
3. 因为划词插件是一排圆形按钮，所以那一镜用按钮逐个点亮、名字浮签升起，而不是整条一起出现。
4. 因为语音是按住才听、松开才停，所以那一镜的胶囊随一条按键按下而出现、松开而收起，声波条跟着动。
5. 因为实时字幕一路一块、一段一行，所以字幕镜头让行从底部逐行顶上来，最新一行带浅色底，和产品里 `latest && isActive` 的高亮一致。

## 反重复

上一支：深色舞台、Mac 机身、真实录屏、无大字、120 BPM 紧凑。本片不用其中任何一项，也不用它的片尾句「选中，即译」。
片内：开场是字、中间是界面、收尾是图标，取景三种；转场只用硬切，不连用同一种入场。

## 叙事

钩子（一句话变两句话）→ 划词浮层 → 划词插件 → 语音 → 实时字幕 → 收尾。完整产品里不进本片的：截图识别、文件翻译、词典、历史、快捷翻译、会议记录，以及整个 Windows 版。

## 画面规范

- 1920×1080，30fps，底色 `#F6F1E8`（暖白），墨色 `#2A2622`，弱墨 `#8A8175`，强调色用图标的青 `#3ED0C4`，只用于一个点。
- 安全区：左右 120px，底部 160px 不放关键文字。
- 字号：主标题中文 92px / 600，英文 28px / 400 Georgia；说明中文 26px / 400。界面按产品的 2 倍：正文 30px、次要 24px、时间码 21px 等宽。
- 动效：入场 0.4–0.7s，ease out；不用回弹，不用旋转，不用彩虹色，不用粒子。
