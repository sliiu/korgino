# 按路分面板

2026-11-03。结论在 `docs/adr/0059-lane-panel.md`。`0057` 的「只吃第一路」作废。

实时和媒体用同一套路面板。一路一块，从上往下排。只有一路时也是一块。字幕不再混成一条列表。每块自己滚动，贴在底部才跟着新行。这一路的笔记打开时，只有这块不跟。

一块面板里：识别引擎，绑定（翻译、译成、沉浸字幕、加翻译、移除翻译），这一路的字幕，这一路的标记，这一路的笔记，清空这一路，移除这一路。

沉浸字幕只有实时的绑定上有。分说话人只有实时有，滑杆留在采集上。

留在外面：

- 实时：采集开关、开始和停止、麦克风设备、电平、识别语言、分说话人。窗口仍按采集分栏。再加一路在面板下面。
- 媒体：文件、播放器、识别语言、起点、音轨、开始、停止、移除这份。

导出仍是这条采集或这份片子点一次，在表里勾路。识别语言一条采集一种，一份片子一种，仍按第一路的引擎收窄。

标记一路一份。媒体从整份片子一份改成跟着路。

一场笔记是这一路的一页，只吃这一路已经切好的段。译文仍是译成母语的那条绑定优先，没有就用第一条有译文的，再没有就只用原文。清空这一路时收起这一路的笔记。停下不收。重新开始或去掉这份片子时，各路的笔记都收起。

删掉一路时，这一路的字幕、标记和笔记一起删掉。停下，或这份片子不在识别，才能删。

开始听或开始识别时收起设置。实时在采集栏头收起，听的时候可以再展开，停下时自己展开。收起的是设备、语言、分说话人，以及每一路的引擎和绑定。这时每块面板只留路名、字幕、笔记和清空。媒体进行时，播放器下面收成一行摘要。

媒体队列只留文件、进度、停止、导出和移除。语言、起点、音轨和开始放在播放器下面、路面板上面。没选中的份看不到这些。

换引擎或换绑定，已经切好的段留在这块面板里。只有清空、删掉这一路、重新开始或去掉这份片子才清。
