# 释义展开时浮层跟着长高（2026-11-03）

`0002` 要求释义和对话用同一种展开。对话做到了：它在译文下面单独占一块，浮层按这块的高度往下长，顶边不动（`0010`）。释义原来放在译文的滚动区里，高度仍按译文量，词条出现在滚动区底部，短译文也要往下滚才看得见。

## 决定

- 释义挪出译文滚动区，跟在译文下面，和对话同一层。
- 浮层高度改成「标题和原文 + 译文 + 释义」的内容高度，仍不超过屏幕里留出一截桌面的那个上限（`0011`、`0013`）。顶边保持第一次摆好的位置。
- 高度够放下时，释义整段都在屏上。不够时（已经顶到上限，或用户把浮层拖矮了），译文在自己的区域里滚，释义至少留出一条可见，多出来的词条在释义自己的区域里滚。不再和译文共用一条滚动。
- 拖过边框的那一次仍然只长不缩（`0012`）。收起释义后，没拖过的浮层收回译文的高度。

## 实现

`Sources/Popup.swift`：测量走内容高度（`huggedColumn`）。浮层已经有真实高度时走 `PopupChatSplit`，释义在下半块，对话打开时再在它下面分一块。

## 补充（2026-11-04）

- 长译文顶到上限时，释义和对话不再只剩一条：下半块按内容拿高度，最多一半，译文在剩下的地方滚。
- 释义、对话的上沿可以拖，拖出的高度记在这次运行里，下一个浮层沿用。拖不过「标题和原文」那一截。
- Free Dictionary 只写英文。读的语言不是英文时，释义用第一家内置翻译服务译成这次的译成语言，英文原句缩小留在下面。查原文时读的是这页的译成语言，查译文时读的是母语。
