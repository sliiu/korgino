# 界面文字

简体是原文，也是查找用的键。写给正在用的那一个人：短句，说发生了什么，再说下一步。不写口号。

润色三档的说明会原样送给模型，所以各语言都按意思写。缩短是把字收到刚说的那件事，不是改成问句。

繁体用台湾的说法：设定、预设、音讯、视讯、网路、即时。

代码里已经在用、目录里没有的 166 句补进了全部语言。日语、韩语、德语、法语、越南语另外缺的 227 句也补上了。西班牙语、荷兰语、土耳其语原先几乎整份是英文，波兰语大片是空的或写坏的，瑞典语把占位符写成了 `Kt0X`，印地语把 `%@` 写成了数字。这几份按同一套说法重写。印地语里权限路径和润色说明是按意思写的，其余句子比日语、德语糙。
