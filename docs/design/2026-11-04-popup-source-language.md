# 浮层可以改原文语言（2026-11-04）

原文语言靠系统检测。短词常判错：`male` 判成意大利语，`apple` 判成土耳其语，`table` 判成法语。

## 决定

- 浮层顶上左边的原文语言改成菜单：自动检测，或手选一种。和目标语言一样，按页记，不写入设置。换一种就重新翻译。
- 新的划词、剪贴板、截图回到自动检测。重新翻译和切标签保留这一页的选择。
- 手选的语言替代检测，进互译方向的判断（`Lang.plan` 的 `source`）。原本就自己检测的谷歌、谷歌云、DeepL 也带上这门语言；默认提示下的 AI 在要求里写明从哪种语言译。
- 查的是原文本身时，词典也按手选的语言走：不是英文就不查 Free Dictionary（它只有英文词条），没有词条时的对译也从这门语言译。
