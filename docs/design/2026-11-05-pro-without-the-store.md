# 不上架时 Pro 怎么来（2026-11-05）

渠道、钥匙、名额、补发、停掉第一台填入的、再买一笔是另一把钥匙、商店包只走 App Store 更新、占着名额的这台可以自己让出，已定，见 `0062`。

## 现在的包

Pro 的购买和 14 天试用都是 StoreKit 商品：`com.sliiu.Korgino.pro`、`com.sliiu.Korgino.trial`。商品列表拉不到时，关于页的购买和试用按钮停着，文案是「这一份不是从 App Store 装的，现在买不了 Pro」。见 `0008`、`0012`、`0028`。

开发版编译开关默认当作已购买，只在开发版里出现。公证包没有这个开关。

Apple 的发行对照表写明：App Store 服务（内购）只在 Mac App Store 的包里可用，Developer ID 的包没有。开发签名的包可以走沙盒，公证过的直接下载完成不了这笔付款。

## 已经否过的

`0012` 否过「公证包里另做网页付款和本机许可」：和 StoreKit 各记各的，国内用户还要另接微信或支付宝。当时的前提是后来仍会上架，并且上架后停发公证包。

## 已选

两份都卖。商店包只认商店购买，含 14 天试用。公证包只认直接购买，没有试用。换包不算已购买。收款是自己的支付系统，应用留购买、填写钥匙和按邮箱补发的接口，不接具体渠道。见 `0062`。

两份现在都是 `com.sliiu.Korgino`。商店包必须进沙盒，公证包没有。同一标识下，后装的那份会变成打开的那一份，购买状态不跟着走。

## 已选的证明

直接购买交回一把钥匙。付款必填邮箱。公证包里可以填邮箱，把同一把钥匙发回去。商店包不认这把钥匙。

两份用同一个标识。后装的换掉先装的。

一把钥匙最多 3 台 Mac。同一台重装不新占名额。第一次填写时向支付系统对一下，对上之后存在本机，断网仍算已购买。

## 已选的名额和失效

第 4 台填入同一把钥匙时，自动停掉第一台填入的那台，不由人点选。每天在用的那台若是第一台填入的，也会被停掉。被停的那台当时若没网，仍算已购买，直到下次连上系统。

补发时一律说「如果这个邮箱买过，钥匙会发到那里」。没有购买也这么说。

有网时再对一次。退款、作废、名额被让出，都在下次连上时变回免费档。连不上保持上次的结果。

钥匙只解开 Mac 公证包。Windows 不认。

启动时和翻译中不弹窗。被停掉的那台在关于页看到自己已让出名额。

占着名额的这台可以在关于页自己让出，只让出自己。有网当时就让出。没网先记在本机，让出完成前仍算已购买，名额要等这台连上才空出来。这段时间里第 4 台填入，停掉的仍是第一台。

同一台再填这把钥匙，仍算当初那一台。已经让出名额的那台再填，是一次新的填入，名额满了就停掉当时的第一台。

同一邮箱再付一笔，得到另一把钥匙，各自 3 个名额。补发时每一把都发。退掉其中一把，只影响那一把。

商店包的更新只走 App Store。检查 GitHub 只在公证包。
