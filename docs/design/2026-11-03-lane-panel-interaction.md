# 路面板的交互收口

2026-11-03。接着 `0059`。

窗口不再套两层滚动。设置展开时整页滚，每块面板最高 420。设置都收起时整页不滚，几块面板分窗口的高度，滚轮只滚字幕。

实时的采集栏头随时可以收起设置，停下时仍自己展开。停下后看字幕，可以收起来让面板变高。

去掉采集的勾不再清掉这条采集的字幕，只是不显示。重新开始仍清。导出本来就只算勾着的采集。

媒体识别完不再摊开设置。播放器下面是摘要和「调整设置」，点开才是语言、起点、音轨、每一路的引擎和绑定，以及重新识别。重新识别开始后自己收起。等待中的片子仍直接摊开。

媒体播放时高亮的那句不在视野里，就滚到刚好露出来。人在拖动或笔记开着时不动。「回到最新」只在识别或监听时出现。

清空有字幕的一路先问一次。没有字幕时直接清。

实时字幕的每一行，修改和删除只在指针停在这一行时出现。朗读一直在，和媒体一样。
